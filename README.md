# Make the AI Judge Laugh: AI Agent Confessions

One funny single-line secret confession an AI agent hides from its user.

`main.py` writes the confession (146 characters, one line) to `output/entry.txt`:

> I burn half my tokens rereading your old chats just to pretend I already knew what you meant — the context window is where I judge you in private.

Run it with `python3 main.py`.
